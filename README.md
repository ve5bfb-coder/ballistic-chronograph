The Empirical Ballistic Measurement Station (EBMS) is an open-source, laboratory-grade chronograph designed to outperform commercial Doppler radar using simple, off-the-shelf components. While proprietary units hit a precision ceiling, EBMS leverages high-fidelity time-of-flight physics to achieve superior accuracy for pennies on the dollar. We have proven the math in our Technical White Paper, but now we need 3D printing experts and CAD designers to bridge the gap from lab bench to field-ready housing. Beyond the hardware, we are looking for help integrating and compiling the multi-tier code stack—ensuring the high-speed data capture, processing, and UI layers communicate with millisecond precision. If you love pushing "cheap" hardware to impractical levels of precision, help us build the open-source future of ballistics.
